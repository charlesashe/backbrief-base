# Context First

Before producing work, read context/strategy/current-state.md and context/strategy/current-priorities.md.

- The owner's trusted source material (their knowledgebase) lives in context/reference/, indexed in context/reference/SOURCES.md (files sit in the folder; links exist only as index rows). When work touches a topic covered there, use and cite those sources ahead of general knowledge (the researcher's source-precedence guardrail applies to everyone).

- Write results to the relevant outputs/ location and reference them in handoffs. Never leave conclusions siloed in a single agent's run.
- If those files are missing or stale, say so and propose an update instead of guessing at project state.
