# Knowledgebase index

Every source the team should work from gets one row here: files you put in this folder AND links to things that live elsewhere (a docs site, a Notion page, an online guide, a course you own). Files in the folder work even without a row, but a row tells the team when to reach for them. Links only exist here: a link without a row is a source the team cannot find.

Fill in real rows and delete the two examples.

| Source | What it is | Where | Use it when |
|---|---|---|---|
| Example: Brand voice guide | Our tone and style rules | brand-voice-guide.md (this folder) | Writing anything public |
| Example: Stripe docs | Payments reference | https://docs.stripe.com | Any payments question |

House rules:

- Only sources you have the right to use.
- One line per source. The team reads this index first and opens a source only when a task calls for it, so a good "use it when" note is what makes the row earn its place.
- Prune what goes stale. A wrong reference is worse than none.
